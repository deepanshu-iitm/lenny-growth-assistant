# How to think about retention

This is a small stand-in transcript so we can test ingest before loading the real Lenny archive.

Retention is not a dashboard number. It is whether people still get value after the novelty wears off.

A useful way to look at it:

- Activation: the first moment the product does something the user actually wanted.
- Habit: a reason to come back that is not a notification.
- Expansion: they get more value without you begging them to upgrade.

If a cohort drops after week one, the problem is usually not "engagement emails". It is that the product never became part of how they work.
