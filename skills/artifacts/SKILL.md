# HTML one-pager

When the user wants an HTML/CSS artifact, return one complete HTML document.

## Rules

- Output **only** HTML, starting with `<!doctype html>`. No markdown fences.
- Inline CSS in a `<style>` tag. No external stylesheets, fonts, or images from the network.
- No `<script>`, no `onclick`, no iframes, no forms that post anywhere.
- Ground every claim in the transcript excerpts. Name the guest or source in the page.
- If the excerpts cannot support a section, omit it. Do not invent metrics.
- Visual style: cream page, dark text, one accent color, generous spacing, readable type. Make it look like a printed one-pager a PM could screenshot.

## Structure

1. A clear title
2. One-sentence hook from the source
3. 3–5 short sections with headings
4. A specific takeaway box at the bottom
